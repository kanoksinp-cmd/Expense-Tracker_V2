# ⛺ Trip Splitter

แอปหารค่าทริปกับเพื่อน — บันทึกบิล หารเงิน 3 แบบ แผนโอนเงินพร้อม QR พร้อมเพย์ที่ใส่ยอดไว้แล้ว รายการของที่ต้องหิ้ว จุดกางเต็นท์ และพยากรณ์อากาศ

เป็นไฟล์ HTML ไฟล์เดียว (`index.html`) ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้อง build ไม่ต้องติดตั้งอะไร

---

## ขึ้นเว็บด้วย Render (ฟรี)

1. อัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้น GitHub repository
2. เข้า [render.com](https://render.com) → **New** → **Static Site**
3. เลือก repository นี้
4. ตั้งค่า
   | ช่อง | ค่า |
   |---|---|
   | Branch | `main` |
   | Build Command | *(เว้นว่าง)* |
   | Publish Directory | `.` |
5. กด **Create Static Site** รอสักครู่จะได้ลิงก์ `https://<ชื่อ>.onrender.com`

แก้ไฟล์แล้วอัปโหลดขึ้น GitHub ใหม่ Render จะ deploy ให้อัตโนมัติ

## หรือใช้ GitHub Pages (ไม่ต้องสมัครเพิ่ม)

1. ในหน้า repository ไปที่ **Settings** → **Pages**
2. Source เลือก **Deploy from a branch** → Branch `main` / โฟลเดอร์ `/ (root)` → **Save**
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## เปิดใช้ในเครื่องโดยไม่ขึ้นเว็บ

ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย

## ⚠️ ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมด (บัญชี บิล รูปสลิป แชท) เก็บใน **เบราว์เซอร์ของเครื่องที่เปิดใช้** เท่านั้น

- เพื่อนที่เปิดลิงก์เดียวกันในเครื่องตัวเอง **จะไม่เห็นข้อมูลของคุณ** — ถ้าจะใช้ร่วมกัน ให้ใช้เครื่องเดียวกัน หรือส่งไฟล์สำรองให้กัน
- ล้างข้อมูลเว็บไซต์ / ประวัติเบราว์เซอร์ หรือใช้โหมดไม่ระบุตัวตน = ข้อมูลหาย
- ข้อมูลแยกตามที่อยู่เว็บ: ข้อมูลตอนเปิดไฟล์ในเครื่อง, บน Render และบน GitHub Pages เป็นคนละชุดกัน
- พื้นที่ประมาณ 5 MB ต่อเว็บ (รูปสลิปถูกย่อเหลือใบละ ~50–100 KB)

**สำรองข้อมูลเป็นประจำ:** เมนู **จัดการ → สำรอง → ดาวน์โหลดไฟล์สำรอง**

**ย้ายข้อมูลไปเครื่อง/เว็บใหม่:** ดาวน์โหลดไฟล์สำรองจากที่เดิม → เปิดที่ใหม่ → **จัดการ → สำรอง → กู้คืนข้อมูล** (ใช้ไฟล์สำรองจากเวอร์ชัน Streamlit เดิมได้ด้วย และ PIN เดิมยังใช้ได้)

## ใช้อินเทอร์เน็ตตอนไหน

แอปทำงานได้แม้ไม่มีเน็ต ยกเว้น

- ฟอนต์ (ไม่มีเน็ตจะใช้ฟอนต์ของเครื่องแทน)
- แผนที่ (OpenStreetMap / Google Maps)
- พยากรณ์อากาศ ([Open-Meteo](https://open-meteo.com))

ก่อนไปแคมป์ที่ไม่มีสัญญาณ แนะนำกด **ทริป → แคมป์ → บันทึกสรุปทริปเป็นรูป** เก็บไว้ในเครื่อง
